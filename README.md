# بناء السيرة الذاتية - النسخة العربية من Resume.io

## نظرة عامة
تطبيق ويب متكامل لبناء السيرة الذاتية باللغة العربية مع دعم كامل لـ RTL، مستوحى من resume.io مع تصميم بألوان بنفسجي وأسود.

## المميزات الرئيسية

### ✨ صفحة الهبوط
- تصميم حديث وجذاب بألوان بنفسجي وأسود
- دعم كامل للغة العربية مع RTL
- عرض الميزات والقوالب المتاحة
- تصميم متجاوب لجميع الأجهزة

### 📝 أداة بناء السيرة الذاتية
- **المعلومات الشخصية**: الاسم، المسمى الوظيفي، البريد، الهاتف، الموقع، النبذة
- **الخبرات العملية**: إضافة/حذف/تعديل خبرات متعددة مع دعم الوظيفة الحالية
- **التعليم**: إدارة الشهادات والدرجات العلمية
- **المهارات**: إضافة مهارات متعددة
- **اللغات**: إدارة اللغات ومستوياتها
- **القوالب**: 6 قوالب احترافية مختلفة (كلاسيكي، عصري، إبداعي، محترف، بسيط، أنيق)

### 💾 الحفظ والتصدير
- حفظ تلقائي كل 3 ثواني
- حفظ يدوي بزر مخصص
- تصدير السيرة الذاتية بصيغة PDF مع دعم النص العربي و RTL
- معاينة مباشرة للسيرة الذاتية

### 🎨 التصميم
- ألوان بنفسجي (#7c3aed) وأسود
- تصميم متجاوب (Responsive) لجميع الأحجام
- استخدام shadcn/ui components
- animations وتأثيرات hover جميلة

## التقنيات المستخدمة

### Frontend
- **React 19** مع React Router
- **TailwindCSS** للتصميم
- **shadcn/ui** للمكونات
- **Axios** للاتصال بـ API
- **Lucide React** للأيقونات

### Backend
- **FastAPI** (Python)
- **MongoDB** لقاعدة البيانات
- **Motor** (MongoDB async driver)
- **ReportLab** لتوليد PDF
- **arabic_reshaper + python-bidi** لدعم النص العربي في PDF

## API Endpoints

### Resume Management
- `POST /api/resume` - إنشاء سيرة ذاتية جديدة
- `GET /api/resume/{resume_id}` - الحصول على سيرة ذاتية
- `PUT /api/resume/{resume_id}` - تحديث سيرة ذاتية
- `GET /api/resumes` - قائمة بجميع السير الذاتية
- `POST /api/resume/{resume_id}/export-pdf` - تصدير PDF
